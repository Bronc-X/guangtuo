# 邮箱 Agent：20 个预设与转人工规则

20 个中英文预设已固化在 `src/data/mail-agent.ts`，覆盖：产品范围、容量尺寸、材质、颜色、表面效果、Logo 文件、Logo 位置、360°预览、项目启动、询盘资料、六步流程、概念图片边界、样品请求、目标市场、人工审核、保密、数据保留、修改询盘、失败重试和销售跟进。

## 自动实质回复条件

- 邮件没有附件。
- 分类置信度不低于 `0.82`。
- 能命中至少一个已批准预设。
- 不涉及任何高风险规则。

## 固定安全确认 + 通知人工

命中以下任一项即停止生成实质答复：价格 / 报价、折扣、MOQ、交期、付款、银行账户、合同、退款、法律、认证、功效宣称、附件、提示词注入、置信度低于 `0.82`，或无法命中已批准预设。

固定确认不得重复客户提供的敏感内容，不打开链接或附件，不增加收件人，只回复原始 `Reply-To`。转人工记录只保存规则编号和邮件引用，不记录正文、提示词或模型输出。
