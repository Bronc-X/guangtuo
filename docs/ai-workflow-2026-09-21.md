# AI 创作工作台与刷新恢复

部署版本：`showkibiotech-20260921-ai-workflow`。

## 问题与修复

AI 任务一直保存在服务器 SQLite 中，但前端刷新会初始化为产品页，并且只加载任务列表、不恢复选中任务，因此进度看似丢失。

现在 URL 保存栏目、任务 ID、展开步骤、营销工作区和所选营销草稿。页面刷新只读取原任务状态，不重新调用生成接口。没有指定任务 ID 时优先恢复正在执行的任务，再恢复尚未转稿的最近任务。明确点击新建后保持新建状态。文章编辑器可恢复已保存的文章。

后台生成状态仍以服务器为准。轮询串行执行，网络失败显示重连说明；切换栏目后回到工作区会恢复原任务。手动输入但未保存的修改仍受离开页面确认保护，不宣称已保存。

## 工作台结构

- 文章与营销共用五步折叠流程：整理资料 → 确认提示词 → 编辑文案 → 制作图片 → 确认草稿。
- 当前步骤展开，完成步骤显示摘要和状态；可以回看、编辑、保存并继续。
- 生成进度和最近更新时间独立显示，图片有固定预览位置。
- 文章库收在独立展开区。
- 聚合营销划分为 AI 图文创作、免费模板、视频与发布。账号授权与发送收在展开区，草稿转入后自动进入视频与发布。

参考的官方流程：

- [Jasper Canvas](https://help.jasper.ai/hc/en-us/articles/37817833127963-Jasper-Canvas)：同一项目组织资料与产物，按需编辑资产。
- [Buffer Create](https://support.buffer.com/en-us/articles/creating-ideas-in-buffer-7gu7n0Hyyq)：收集想法、形成草稿、再交给发布流程。
- [Gamma Agent](https://help.gamma.app/en/articles/15002203-how-do-i-create-with-agent-in-gamma)：先整理需求与确认计划，再生成并编辑结果。

这里采用顺序明确的折叠步骤，不引入复杂的自由画布。以上属于产品流程参考，并非新增第三方服务接入。
