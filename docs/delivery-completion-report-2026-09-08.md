### 邮件行为与权限

- 初稿是六语规则生成，并非已经接入模型的自主邮件 Agent。商业条件和最终回复需人工核对。
- 只有管理员能看完整询盘；会话和 CSRF 保护后台写入，公开查询只使用访问令牌且不返回个人资料。
- 编辑会撤销旧批准；收件人固定为该询盘邮箱；确认版本和实际发送是两个动作。
- SMTP 只支持 TLS 465 或强制 STARTTLS 587，保留证书校验。缺少配置时询盘仍保存，明确标记未发件。
- 最多三次人工尝试；超时、中断或不确定结果需先核对发件服务，再决定是否重试，不能自动重发。
- “发件服务已接收”不代表进入收件箱、客户已阅读或已作出商业承诺。

### 文件与发布边界

- JPG/PNG/WebP 和普通 PDF 单文件不超过 8 MB。PDF 需可解析、未加密、1 至 100 页；拒绝检测到的脚本、动作、表单和嵌入内容。此校验不替代专业杀毒或资料授权审查。
- PDF 不进入图片选择器，草稿文件不公开，下载使用附件响应头。
- 构建输入与环境受限，不向 Next 构建传入 SMTP、AI、管理员等服务密钥。
- Linux 使用软链接原子切换；Windows 本地采用带备份恢复的 junction 切换，不宣称原子性。
- 构建失败时保留上一个网站版本。若网站已经切换、数据库发布记录随后同步失败，需要核对 `release.json` 和私有日志，不能宣称跨文件系统与数据库的所有失败都能自动回滚。
- 修复 Next 16.3 Windows 静态导出的 RSC 分段文件名不一致，发布前补齐客户端请求的扁平文件名，保留原文件；对应回归已通过。

### 3D 与 AI 生成边界

- Logo 只接受可解码栅格图片，不超过 2 MB、2048px；分享链接不携带 Logo，避免公开品牌资产。
- 包装选择以可读本地化字段带入询盘。导出的 PNG 是网页效果图，不替代生产工程图或样品确认。
- Chrome 实际鼠标拖拽已观察到旋转。单指旋转和双指缩放使用真实 OrbitControls 的自动化事件测试，不能替代物理手机验收。
- 首次不支持 WebGL、上下文丢失、GLB 404 都有明确失败界面；故障只在隔离 QA 服务注入。重试清理模型缓存。
- 去除远程 HDR 环境图依赖，现有模型使用本地光照环境。
- 生成任务支持同一 API、同一浏览器 24 小时恢复、错误重查和轮询超时；恢复不会自动创建付费任务。
- 真实图片服务、GPU worker、模型许可、访问控制和费用上限尚未确认。普通 2 核 2 GB 服务器不能被当成已交付的 GPU 生成服务。

SMTP 结项补证使用 [smtp-loopback.ts](../scripts/delivery-qa/smtp-loopback.ts)：创建一天有效的本机测试证书，服务器仅监听 `127.0.0.1:465` 和 `127.0.0.1:587`。没有信任该证书时，真实 Nodemailer 连接被拒绝且没有发送认证；在仅测试子进程中通过 `NODE_EXTRA_CA_CERTS` 信任后，走真实 CMS HTTP 提交、管理员登录、CSRF、审核确认与 SMTP 认证。第一次 DATA 人为返回 451，后台记录失败；第二次人工重试被接收；第三次点击未产生重复邮件。每种模式仅接收一封 `.test` 地址的本地测试消息。进程结束后关闭两处监听，不修改系统证书、不连接外部发件服务。新增脚本通过类型检查和零警告 ESLint。

复验命令为 `pnpm exec tsx scripts/delivery-qa/smtp-loopback.ts`，需要本机 OpenSSL 和未被占用的 465/587 端口（某些系统需相应低端口权限）；端口占用时直接失败，不结束其他进程。私有 QA 数据留在 `tmp/smtp-loopback-*`，不会进入 runtime 打包白名单。

## 5. 正式上线顺序与所需输入

1. 用户完成服务器付款/创建，提供本账号新服务器的公网 IP 和授权登录方式。不要复用其他账号下的旧服务器。
2. 按配套部署说明安装 Ubuntu runtime，上传两个归档，创建唯一管理员。后台端口 3111 只监听回环，公网仅开放所需端口。
3. 设置 `@` 与 `www` 的 DNS、HTTPS 和续期；验证首页、六语、`/api/health`、匿名后台 401、后台登录、正式域名上传及发布。最近一次本地 DNS 查询仍为 NXDOMAIN，不是全球 DNS 结论。
4. 用户提供专用发件邮箱/SMTP 服务商和允许测试的收件人；密码只在服务器私有环境文件填写。配置发件域名记录后进行真实收件验收。
5. 验证重启后询盘与文件仍在、备份可恢复；检查手机实机及客户素材授权。若包含付费 AI 新造型，单独完成服务接入和许可确认后再启用。
