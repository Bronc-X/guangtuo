# 生产接入与核心功能验收

## 1. 3D 模型与效果图

Studio 分成两条交付路径。现有包装直接从 CDN 加载已审核的轻量 3D；新造型先由服务端生成方案图，用户确认后再交给私有 GPU worker 生成几何。客户设备只负责显示和交互，不安装模型权重、CUDA 或生成服务。

每个正式公开 SKU 仍应提供经过授权、人工审核和部件拆分的 GLB；纹理优先 KTX2。模型在导入前须通过 Khronos Validator，并用 glTF-Transform 检查体积、纹理和未引用资源。

新造型生成结果同时保留两份：原生高精度母版留在服务端用于后续修模，浏览器只获得约 10 万三角面的预览版。公开网站建议预算仍为单产品不超过 5 MB、约 10 万三角面、1K/2K 纹理。性能派生不得覆盖母版；没有正式模型时页面只显示概念预览，不能作为打样依据。

生产链路：

```text
客户浏览器 → HTTPS Studio API → 方案图服务
                            → 私有 GPU worker
                            → 持久缓存/CDN → 客户浏览器
```

前端只提交包装类型、造型说明、规格、方案图编号和随机种子。模型、步数、网格分辨率与硬件配置只存在于服务端。相同请求会合并，完成结果可跨网关重启复用；公开编号与内部缓存键分离。生成结果仍必须经过浮片/孔洞/法线检查、人工校尺寸、部件拆分、UV/PBR、性能派生和正式批准。

上线验收逐 SKU 检查：

- 鼠标、触控均可 360°旋转，缩放范围受控。
- 所有合法预设能加载；不合法组合不得生成链接。
- 颜色/材质/结构改变后，分享链接可恢复同一配置。
- “导出当前效果图”生成 PNG；导出图需标注“概念效果图，以工程确认和实物为准”。
- WebGL、WASM、GLB、KTX2 加载失败或上下文丢失时，回退到海报与参数表。

## 2. AI 方案与邮件回复

生产流程必须是异步的：`POST /v1/inquiries` 返回 `202 + jobId`，SQS Worker 调用 Bedrock，DynamoDB 保存状态；前端每 2–3 秒查询，55 秒进入降级，60 秒前必须得到 `completed` 或 `retryable_error`。

模型输出先通过六段式 Schema 验证，再进入邮件草稿。以下任一情况禁止自动实质承诺，转人工确认：价格、折扣、MOQ、交期、付款、银行、合同、退款、法律、认证、功效、附件、低置信度或提示词注入。

仓库现已包含 Bedrock Converse Worker：只向模型发送业务配置字段，不发送姓名或邮箱；系统提示明确将询盘内容视为不可信数据，输出必须通过六段式 Schema。模型 ID 未批准时 Worker 会安全停止并由 SQS/DLQ 保留任务。

网站邮件默认流程：

```text
询盘 → AI 六段式草稿 → 服务端规则检查 → 人工批准
    → SES 队列 → 发送/重试 → 状态页
```

只有客户书面授权后才能开放指定低风险场景的自动发送。SES 上线前完成生产权限、DKIM、SPF、DMARC、MAIL FROM、退信/投诉告警和 DLQ 演练。

SES Worker 只接受数据库中状态为 `approved` 的邮件，只向草稿原始单一收件人发送；`pending_review` 会被拒绝。正式审核人身份仍需接入 Entra/OIDC Authorizer 后才可开放审批接口。

Microsoft 365 收件箱 Agent 是独立变更项：专用邮箱、Entra 证书认证、Application RBAC 单邮箱授权、Graph webhook + delta sync。它不读取附件、不点击链接、不新增收件人，并只回复原始 `Reply-To`。

## 3. 部署边界

- 前端：Next.js 静态导出 `out/` → 私有 S3 → CloudFront OAC。
- 动态能力：Regional REST API Gateway + WAF → Lambda → DynamoDB/SQS → Bedrock/SES。
- 3D Studio：独立 HTTPS 容器/虚拟机网关 → 私有 GPU worker → 共享队列、数据库和对象存储；不放入短时 Lambda，也不连接客户电脑。当前仓库已实现单实例磁盘缓存与私有 worker 边界，多实例共享基础设施仍需部署。
- 静态前端不得使用 SSR、ISR、Server Actions、Cookie 语言检测或 Next 默认图片优化。
- 安全响应头配置在 CloudFront；API 仅允许正式域名 CORS。
- 生产日志不得记录邮箱、电话、询盘正文、提示词或模型输出。
- 数据默认保留 12 个月，应用日志 30 天，安全审计 90 天；令牌只存哈希。

## 4. 发布门槛

- 10/10 固定 AI 案例在 60 秒内完成或给出明确可重试错误；至少 9/10 首次具备完整六段结构。
- 五组邮件案例覆盖变量、批准、发送、失败和重试。
- 全部正式 SKU 与启用预设完成 3D、效果图和降级测试。
- S3 非公开、WAF/CORS/限流/幂等有效，且日志扫描无个人信息。
- Bedrock 模型必须在新加坡单区域可用并通过固定案例；否则停止上线并取得跨区域处理书面批准。
