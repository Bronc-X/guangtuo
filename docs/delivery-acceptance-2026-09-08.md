## 上传 API 实测

使用独立临时数据库与生成的 QA 图片，未改客户已发布内容。PNG、JPEG、WebP 上传返回 201；大于 8MB 返回 413；伪装 PNG 和 PDF 返回 415；未登录返回 401；错误 Origin、缺少 CSRF 返回 403。登录后草稿图片预览 200，匿名预览 401，退出后会话失效。上传前后已发布快照哈希相同。

证据：[接口结果](../output/delivery-qa-20260908/cms-api.json)、[原后台错误截图](../output/delivery-qa-20260908/admin-original-failure.png)。

独立后台浏览器验证通过：登录 → 上传 PNG → 图片进入文章封面选项 → 新建文章 → 保存草稿 → 确认发布 → 查看发布记录。草稿未进入已发布 JSON，确认后文章和图片出现在隔离环境。新文章 HTTP 200、含测试标题与上传图片路径，图片 HTTP 200 / image/png；客户工作区的已发布内容字节未变。

注意：`publisher.ts` 写入 JSON 与公开图片后直接将记录标为 `live`，没有触发 `next build` 或上传部署。开发服务器会随内容更新，静态线上包则不会；因此后台的“已上线”不能作为正式站已更新的依据。生产须补上后台进程、持久存储、同站 HTTPS 代理和实际构建发布任务。

证据：[发布数据](../output/delivery-qa-20260908/cms-publish.json)、[保存草稿](../output/delivery-qa-20260908/cms-draft-saved.png)、[确认发布后](../output/delivery-qa-20260908/cms-published.png)、[发布记录](../output/delivery-qa-20260908/cms-release-history.png)、[测试文章网页](../output/delivery-qa-20260908/cms-article-public-page.png)。

## 邮件顾问与询盘

实测了产品问答、价格/交期承诺及提示词注入。常规产品问题返回预设答案；商业承诺与注入问题得到转人工确认的固定回复。网页顾问是本地预设匹配，不是已经连通客户收件箱的自主邮件 Agent。

完整引导可把姓名、测试邮箱、公司、产品类别与选择写入询盘表。发现自由输入内容丢失和面板未关闭后，修改 `src/components/mail-agent-widget.tsx`，重跑同一浏览器脚本，已确认备注包含“5000盒…”原问题且面板关闭。

有效测试询盘进入本地状态页；URL 没有 `mode=remote`，任务存在 sessionStorage，页面明确显示“这是网站演示环境，您的信息尚未实际发送”。没有任何真实邮件送达证据。仓库提供 AWS 的 API/Worker 适配器，但当前阿里云静态部署脚本没有承载它们。之前“不需要 AWS”的结论仅适用于静态站；要启用真实邮件，仍须部署现有 AWS 后端，或将服务适配并部署到阿里云。两者都不能由 Nginx 静态文件替代。

17 项 Python Studio API 合约测试通过，涵盖请求、缓存、任务恢复和预览派生；没有执行真实图片生成/3D 生成，没有证明外部模型服务可用。鼠标/真机触控拖拽、WebGL 禁用或资源加载失败时的降级、全球网络下远程 HDR 环境图可达性仍需补测。当前预览使用外部 HDR 资源，正式站应纳入资源可达性检查。
