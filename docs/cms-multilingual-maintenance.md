# 中文维护与六语言发布

后台以中文为内容源，发布时用本机 Argos Translate 1.11 / CTranslate2 CPU 引擎生成英语、法语、西班牙语、俄语和阿拉伯语。无需顾问模型、API 密钥、订阅或按字付费；机器、磁盘和运行资源仍由部署环境承担。模型安装需要联网，正常翻译不向外部服务提交文本。

## 日常操作

1. 在原有后台栏目编辑中文并保存草稿。
2. 点击发布。页面显示“正在翻译并发布全部语言”。先翻译，再构建全部网站页面，最后统一切换版本。
3. 发布成功后查看对应外语页面。翻译、校验或构建失败时，草稿保留，旧网站保持可用；发布记录保留失败原因。不要在结果未知时反复点击发布。

| 后台维护范围 | 前端同步位置 |
| --- | --- |
| 首页标题、介绍、首屏图 | 六语言首页及对应标题、描述 |
| 固定页面标题和介绍 | 对应页面首屏与页面标题、描述 |
| 联系我们标题和介绍 | 已合并的“关于我们”联系区域 |
| 公司介绍、视频名称 | 六语言“关于我们” |
| 邮箱、社交账号、二维码、视频链接 | 各语言共用同一字段值 |
| 产品名称、介绍、亮点、用途、净含量、包装 | 产品详情与使用同一目录的列表、卡片 |
| 起订量数值、单位、产品图片 | 各语言同步数值、单位枚举和图片 |
| 膜型名称、功效、规格、起订量、包装、图片 | 对应类别中的技术膜型列表 |
| 证书标题、类型、权利人、编号、原件 | 专利资质页面；编号、原件链接不翻译 |
| 文章标题、摘要、分类、正文、封面 | 六语言文章列表、详情、静态路由与语言切换 |

图片和 PDF 内容本身不会重新绘制或翻译；文件替换在引用它的内容发布后同步。客户询盘、邮件草稿、密码等私有内容不进入网站翻译流程。后台尚未开放的网页布局、导航、固定段落和 3D 参数仍不属于内容编辑字段。

## 安装

需要 Python 3.12、Node 及现有项目依赖。在项目目录运行：

```text
pnpm translation:setup
```

安装脚本在项目内创建被 Git 忽略的 `.venv-translation`，下载 `zh→en`、`en→fr/es/ru/ar` 五个方向的模型。语言模型大约数百 MB，Python 依赖另占磁盘空间。中文至其他语种经英语中转。

默认使用项目虚拟环境的 Python，也可在服务端设置 `CMS_TRANSLATION_PYTHON` 指向已有安装。`CMS_PROJECT_DIR` 指向部署的项目根目录。部署包包含翻译脚本与术语表，但不包含本机虚拟环境和模型文件；新环境必须安装。

Linux 的 CMS 服务启用了 `ProtectHome`。为安装过程与运行服务设置一致的 `XDG_DATA_HOME`、`XDG_CACHE_HOME`、`XDG_CONFIG_HOME`，例如分别使用 `/var/lib/showkibiotech/translation/data`、`cache`、`config`。这些目录应由 CMS 服务账户读写，不能放在公开站目录。勿将模型仅装在 root 用户目录。

翻译按目标语言依次运行，单个模型用 CPU int8 和两条计算线程，完成后释放再加载下一模型。翻译进程退出后才启动网站构建。仍需在正式机器验证资源峰值；本地成功不代表已验证小规格服务器容量。

Nginx 的 CMS 请求等待上限已调整为 2760 秒，覆盖翻译的 30 分钟上限和构建的 15 分钟上限。自定义入口代理也需允许相同等待时间。

## 缓存与质量

译文与当前中文一起保存进发布快照。私有数据目录的 `translations` 保留按原文、语种和翻译版本划分的缓存；原文没变不重复翻译。修改翻译脚本或术语表会使版本变化，下一次发布重新生成译文。老快照仍能正常读取；第一次重新发布会补齐译文，不需要人为改一个字才能发布。

`content/maintained-translations.json` 保存按完整原文匹配的既有译文，未修改的原文优先沿用；中文修改后不再匹配旧译文。`services/translation/glossary.json` 固定品牌与护肤术语。数字在翻译过程中原样保护，证书编号、稳定 ID、网址和素材路径不进入翻译。校验会拦截缺失译文、残留中文、数字丢失和意外 HTML。

免费模型是机器翻译，不保证语法流畅或行业语义完全准确，尤其是经过英语中转的译文。自动校验只检查完整性及上述约束，不等于人工语言审核。应抽查关键功效、法规和权利人表述，术语表需要随实际业务维护。

## 验证与上线

```text
pnpm exec vitest run tests/content-admin tests/published-content.test.ts
pnpm exec tsx scripts/verify-cms-translation.ts --build
```

第二条命令读取公开内容和后台种子，在 `artifacts/cms-translation-check` 生成隔离快照、六语言静态站和检查结果；不会修改客户数据库、当前内容快照或线上网站。覆盖首页、六个页面、产品、膜型、资质、文章的实际译文和页面输出。

部署前备份私有数据库、内容快照及当前站点；将模型装入服务账户可访问的位置，再更新代码及代理配置。上线后用一次真实内容发布检查六语言页面、发布记录及服务器资源。这一生产操作需单独确认，不能把隔离构建当作线上已经更新。
